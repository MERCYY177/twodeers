# 双人空间本地整合升级交付说明

## 本轮范围

本轮以用户上传的 `twodeers-main.zip` 为唯一本地底稿，未连接或修改 GitHub 远程仓库，也未部署、合并或创建远程提交。

### 页面与参数架构

- 首页增加独立「信件」入口。
- 参数区改为七个独立二级页面入口：空间资料、聊天设置、信件与字卡、朋友圈设置、显示与个性化、通知与通话、隐私与数据管理。
- 原有控件通过占位节点移动到对应二级页面，未复制一份新的设置状态，也未改动原有存储键。
- 朋友圈设置仍进入 Circle 自己的页面；朋友圈数据继续使用原独立存储。

### 信件系统

- 新增独立信箱、收件列表、写信、阅读、手动回复、自动来信、自动回信和延迟任务。
- 新增独立草稿箱，输入时自动保存，支持继续编辑、删除和寄出。
- 信件卡片片段保存 `cardId` 与 `textSnapshot`，不会把普通手写信件误记成字卡使用。
- 自动任务在页面可运行时处理，并在重新获得焦点/恢复可见时补处理到期任务；不承诺网页被系统强制停止时准点执行。

### 字卡与最近使用

- 聊天字卡仍使用原 `state.cardPhrases`，旧用户字卡不会迁移成另一份池。
- 朋友圈动态字卡、朋友圈回复字卡仍保存在 Circle 独立状态中。
- 新增统一管理入口，三个池分别编辑、不混合，并提供独立随机预览与“确认已使用”入口。随机预览不记入最近使用，确认后才记入。
- 新增稳定 cardId 和文字快照；删除/调整前置卡片时尽可能按文本匹配保留剩余卡片 ID。
- 最近使用记录区分来源，并只在实际发出/展示时记录；普通选中、预览不计入。

### 通知与通话

- 保留原语音/视频外呼、主动来电设置。
- 新增朋友圈互动应用内通知开关。该开关只控制应用内点赞/评论通知记录，不等同 Android 系统推送；系统级推送仍未实现。

### 备份与恢复

- V4 总备份和参数备份增加 `mailbox-data.json`、`card-system.json`，包含信件、草稿、字卡稳定 ID、最近实际使用记录及朋友圈动态/回复字卡。
- V4 参数备份补入 `chatBeautifyPresetId`；收藏恢复会过滤掉当前表情库中不存在的 ID，避免悬空收藏。
- ZIP 导入加强 manifest 资源数量/总字节数交叉校验，并检查本地文件头与中央目录的名称、标志位、方法、CRC 和长度一致。
- 恢复增加互斥、操作遮罩、旧回复取消、媒体读取代次失效、媒体 URL 缓存清理、Circle/信件任务暂停。
- 主状态写入后执行回读校验；失败时对主状态、Circle、媒体、字体、信件、字卡逐域回滚并检查，回滚失败会在错误信息中列明。

### 数据清理

- 重置双人空间时增加信件、草稿、卡片历史和字体库清理；朋友圈独立存档仍不删除。

### 追加的恢复一致性处理

- V4 导出期间冻结主状态快照，并暂停 Circle/信件后台任务，避免 ZIP 内各数据域来自不同时间点。
- V4 导入与导出互斥；旧版 V3 JSON 导入也增加互斥、任务暂停、写入回读和跨域失败回滚。
